# slides/

Nơi lưu **slide / tài liệu buổi học** (PDF, PPTX…) ngay trong repo cho tiện tra cứu khi code.

> [!important]
> Toàn bộ nội dung thư mục này **được `.gitignore`** — chỉ riêng file `README.md` này được commit.
> Slide **không** được đẩy lên remote (tránh nặng repo + vấn đề bản quyền tài liệu khoá học).

## Nội dung hiện có (local, không commit)

Ưu tiên các slide về **cách làm việc / methodology / clean code**:

```
slides/
├── Skills-for-Coders/
│   ├── 01 - Git & GitHub Fundamentals.pdf   (+ link YouTube .txt)
│   ├── 02 - Git Branching Strategy.pdf
│   ├── 03 - Agile Framework.pdf
│   └── 04 - Jira.pdf
└── M01W01/
    └── M01W01 - Teamwork Tools - Slide_v2.pdf
```

Bản gốc đầy đủ vẫn lưu ở OneDrive (`AIO2026/M01-Skills-for-Coders/`, `AIO2026/M{NN}W{NN}/`) và được index trong Obsidian vault.
