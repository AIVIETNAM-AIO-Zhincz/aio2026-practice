# slides/

Nơi lưu **slide / tài liệu buổi học** (PDF, PPTX…) ngay trong repo cho tiện tra cứu khi code.

> [!important]
> Toàn bộ nội dung thư mục này **được `.gitignore`** — chỉ riêng file `README.md` này được commit.
> Slide **không** được đẩy lên remote (tránh nặng repo + vấn đề bản quyền tài liệu khoá học).
